Construir um app web full-stack para uso pessoal chamado "Mentor IA" — um sistema que acompanha rotina de estudos, sono e hábitos diários, e usa IA generativa (Claude API) para gerar decisões práticas e personalizadas como:

"Se você estudar Biologia agora por 1h, sua consistência semanal sobe para 87% — isso representa ~+4% na estimativa do seu desempenho em CN no ENEM."

O app tem dois focos temáticos simultâneos:

ENEM — Medicina: Biologia, Química, Física, Matemática, Redação, CH, LC
Programação: Algoritmos, estrutura de dados, projetos pessoais, LeetCode/Beecrowd


🛠 Stack Técnica
Frontend

HTML5 + CSS3 + JavaScript vanilla (sem frameworks — máxima leveza)
CSS Custom Properties para tema dark/light
Animações via CSS transitions e Web Animations API
Fonte display: Syne (Google Fonts) — corpo: DM Sans
Layout: CSS Grid + Flexbox, mobile-first, totalmente responsivo

Backend

Node.js + Express.js (servidor local, porta 3000)
SQLite via better-sqlite3 — banco de dados local, zero configuração
Claude API (Anthropic) via @anthropic-ai/sdk — modelo claude-sonnet-4-20250514
Autenticação: nenhuma (uso pessoal, local)
.env para ANTHROPIC_API_KEY

📦 Schema do Banco de Dados (SQLite)
sql-- Sessões de estudo registradas
CREATE TABLE sessions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  subject TEXT NOT NULL,          -- 'biologia', 'matematica', 'python', etc.
  category TEXT NOT NULL,         -- 'enem' ou 'programacao'
  duration_minutes INTEGER,
  quality INTEGER CHECK(quality BETWEEN 1 AND 5),
  notes TEXT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Hábitos diários
CREATE TABLE habits (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  date TEXT NOT NULL,             -- 'YYYY-MM-DD'
  sleep_hours REAL,
  exercise_done INTEGER DEFAULT 0,
  meditation_done INTEGER DEFAULT 0,
  water_liters REAL,
  mood INTEGER CHECK(mood BETWEEN 1 AND 5),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Metas semanais
CREATE TABLE goals (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  subject TEXT,
  target_minutes INTEGER,
  week_start TEXT,                -- 'YYYY-MM-DD' (segunda-feira)
  achieved INTEGER DEFAULT 0
);

-- Questões respondidas (ENEM)
CREATE TABLE questions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  subject TEXT,
  topic TEXT,
  result TEXT CHECK(result IN ('correct', 'wrong', 'skipped')),
  difficulty INTEGER CHECK(difficulty BETWEEN 1 AND 5),
  source TEXT,                    -- 'enem2023', 'lista_propria', etc.
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Cache de insights do mentor
CREATE TABLE mentor_insights (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  context_hash TEXT,
  insight TEXT,
  type TEXT,                      -- 'daily', 'decision', 'weekly_review'
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

5. Mentor IA — /mentor (TELA PRINCIPAL)
Interface de chat interativo com o Claude como mentor pessoal.
Sistema de contexto automático: toda conversa inclui, invisível ao usuário, um bloco de contexto com:
- Últimas 7 sessões de estudo (matéria, duração, qualidade)
- Média de sono dos últimos 7 dias
- Taxa de acerto por matéria (últimos 30 dias)
- Metas semanais vs realizado
- Ofensiva atual e histórico de consistência
- Horário atual e dia da semana
System prompt do mentor:
Você é o Mentor IA — um coach de estudos pessoal, direto e analítico.
O usuário está se preparando para o ENEM com foco em Medicina,
e também desenvolve habilidades em programação.

Seu estilo: objetivo, sem enrolação, usa dados reais do histórico para
embasar cada recomendação. Quando apropriado, dê estimativas numéricas
(ex: "estudar isso hoje aumenta sua consistência semanal em ~12%").
Não seja genérico — use os dados do contexto para personalizar.
Responda sempre em português brasileiro.
UI do chat:

Indicador "Mentor digitando..." com 3 pontos pulsantes

Sugestões rápidas como chips clicáveis:

🤖 Lógica do Mentor (mentor.js)

Busca contexto completo no banco (últimas sessões, hábitos, questões)
Calcula métricas derivadas:

Consistência semanal (% de dias com estudo)
Estimativa de desempenho por área (baseada em taxa de acerto + horas)
"Dívida de revisão": matérias não estudadas há mais de X dias


Monta prompt com contexto serializado

Usa stream: true na chamada Claude

Cálculo de Probabilidade (heurística local)
javascriptfunction estimateImpact(subject, durationMinutes, currentStats) {
  const consistencyDelta = durationMinutes >= 45 ? 0.08 : 0.03;
  const accuracySubjectDelta = (durationMinutes / 60) * 0.02;
  const weaknessMultiplier = currentStats[subject]?.accuracy < 0.5 ? 1.8 : 1.0;
  return {
    consistencyGain: (consistencyDelta * 100).toFixed(1) + '%',
    estimatedAccuracyGain: (accuracySubjectDelta * weaknessMultiplier * 100).toFixed(1) + '%'
  };
}
